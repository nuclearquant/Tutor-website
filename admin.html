How logins and oversight really work here

Read this once. Usernames, PINs and passwords are checked inside the browser, because this site has no server yet. That is enough to keep tutors and students out of each other's dashboards by accident, but a determined person could bypass it. Message oversight leaves no trace on their screens — but anyone who opens this console can read the same conversations, so the PIN on it is the only thing protecting them. Don't store anything truly sensitive until you move the data to Supabase (README-dashboards.md), which adds real accounts and server-side checks.
